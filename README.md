# Portfolio - Esther MENSAH 🚀

Bienvenue sur le code source de mon portfolio professionnel. Ce site web monopage a été conçu pour présenter mon profil, mon parcours académique et professionnel, mes projets, ainsi que mes compétences à l'intersection des **Télécommunications, Réseaux et du Développement Web**.

## 🌟 Aperçu du Projet

Ce projet est une application web moderne, hautement réactive (responsive) et optimisée pour une expérience utilisateur (UX/UI) de qualité. Il inclut un thème sombre élégant et des animations fluides.

### Fonctionnalités Clés
- **Internationalisation (i18n)** : Support complet en Français et Anglais via un React Context personnalisé.
- **Responsive Design** : Interface parfaitement fluide sur ordinateurs, tablettes et smartphones.
- **Animations fluides** : Utilisation de `motion/react` pour des transitions naturelles (effets d'apparition, défilement fluide).
- **SEO & Performances optimisées** : Balises meta adaptées et structure sémantique pour un bon référencement.

## 🛠️ Stack Technique

- **Frontend** : [React](https://react.dev/)
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **Style** : [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations** : [Motion (Framer Motion)](https://motion.dev/)
- **Icônes** : [Lucide React](https://lucide.dev/)
- **Outil de Build** : [Vite](https://vitejs.dev/)

## 🚀 Installation & Exécution Locale

Pour lancer ce projet sur votre machine locale, suivez ces étapes :

### Prérequis
- [Node.js](https://nodejs.org/) (Version 18 ou supérieure recommandée)
- `npm` ou `yarn`

### Commandes
1. Clonez le dépôt (ou téléchargez les fichiers) :
   ```bash
   git clone https://github.com/esther-dorcas/esther-portfolio.git
   cd esther-portfolio
   ```

2. Installez les dépendances :
   ```bash
   npm install
   ```

3. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```

4. Ouvrez votre navigateur à l'adresse indiquée (généralement `http://localhost:5173`).

## 📂 Structure du Code

- `/src/components` : Composants réutilisables (Navbar, Hero, About, etc.).
- `/src/context` : Gestionnaires d'états globaux (ex. `LanguageContext` pour l'i18n).
- `/src/i18n` : Fichiers de traductions (FR / EN).
- `/public` : Actifs statiques (favicon, images, etc.).
